เสนอแก้: แยก "Console เครื่องนี้" กับ "ทั้งระบบ (Server)" ให้ชัด
Console เครื่องนี้ การแสดงผล การเชื่อมต่อ บัญชีของฉัน ทั้งระบบ (Admin) Sign-in นักเรียน ใหม่ Staff session ใหม่ รหัสฉุกเฉิน ใหม่ ความปลอดภัย (HTTPS) ใหม่ สำรองข้อมูล ใหม่ เกี่ยวกับ

การแสดงผล

จำนวนหน้าจอที่เปิดดูพร้อมกันได้สูงสุดจำนวนเครื่องสูงสุดใน Live View / Screen View
รีเฟรชข้อมูลอัตโนมัติทุกกี่วินาทีClients / Rules / Logs / Users
คงการเชื่อมต่อไว้เมื่อออกจาก Live Viewค่าเริ่มต้นคือปิดทั้งหมดเมื่อออกจากหน้า
แสดงปุ่ม Tailscale ในแผงคำสั่งงานดูแลเครือข่าย ไม่ใช่งานคุมห้อง จึงซ่อนไว้เป็นค่าเริ่มต้น
