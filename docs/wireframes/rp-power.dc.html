เปิดเครื่องจ อ พ พฤ ศ ส อาเวลา Wake-on-LAN
ปิดเครื่องจ อ พ พฤ ศ ส อาเวลา เตือน 5 นาที
ปิดเครื่องว่างเครื่องที่ไม่มีใครล็อกอินนานเกิน นาที (หลัง 15:00)
ข้ามวันหยุดได้: · ปิดเครื่องตามเวลา ใช้คำสั่งที่มีอายุ (เครื่องที่ปิดอยู่แล้วจะไม่ดับเองตอนเปิดวันหลัง)
เปิดเครื่องตอนนี้ (Wake-on-LAN) ส่งจาก Server ในวง LAN เดียวกัน · ต้องเปิด WoL ใน BIOS ทุกเครื่องก่อน (งานตอนลงแล็บ)
ผลล่าสุด: ส่งไป 40 · ตื่น 37 · ไม่ตอบ 3COM-04, COM-17, COM-38 → ตรวจสาย LAN / BIOS
ทำไมไม่ทำผ่าน Tailscale/WiFi WoL ทำงานแค่ในวงสาย LAN เดียวกัน (สอดคล้องกับแผนเดินสายแลนแทน WiFi ที่ตัดสินไว้แล้ว)
