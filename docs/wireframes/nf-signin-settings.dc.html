Console เครื่องนี้ การแสดงผล การเชื่อมต่อ บัญชีของฉัน ทั้งระบบ (Admin) Sign-in นักเรียน Staff session รหัสฉุกเฉิน ความปลอดภัย (HTTPS) สำรองข้อมูล

Sign-in นักเรียน

เปิด / ปิด

บังคับล็อกอินก่อนใช้เครื่องปิด = ใช้เครื่องได้เลยแบบเดิม
เปิดโหมด guestให้เข้าใช้แบบไม่ระบุชื่อได้ (บันทึกเป็น guest)
ใช้รหัสฉุกเฉินได้เมื่อ Server ล่มตั้งค่า Authenticator ในหน้า "รหัสฉุกเฉิน"

รหัสผ่าน

ความยาวขั้นต่ำนักเรียนเด็กควรสั้นพอจำได้
บังคับเปลี่ยนรหัสตอนล็อกอินครั้งแรกหลังนำเข้าหรือรีเซ็ต
ล็อกบัญชีเมื่อกรอกผิดครู/Admin ปลดได้
ครั้ง

การใช้บัญชี

บัญชีเดียวล็อกอินหลายเครื่องพร้อมกันห้าม = กันยืมบัญชีกัน · เครื่องเก่าจะถูก logout
ออกจากระบบเองเมื่อไม่ได้ใช้ไม่ขยับเมาส์/คีย์บอร์ด
นาที
