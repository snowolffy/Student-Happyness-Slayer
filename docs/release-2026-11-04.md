## ลำดับติดตั้ง

1. **Server ก่อน (192.168.17.249)**
   - คัดลอก `C:\ProgramData\OnionProcOparetor\onionprocoparetor.db` และ `activitylog.db` ไปเก็บไว้ที่อื่นก่อน เพราะ Server ตัวใหม่จะ migrate DB เองตอนเริ่ม และย้อนกลับไม่ได้
   - ลง `Server-Console-Setup.msi` ทับของเดิม
   - เปิด Console แล้วล็อกอิน ต้องเห็นเครื่องเดิมครบ
   - ถ้า Server ไม่ขึ้น ให้ดู `server.log` บรรทัด "กำลัง migrate..."
2. **Console เครื่องครู:** ลง MSI ตัวเดียวกัน (เลือกเฉพาะ Console ได้)
3. **Agent ลง pilot 2–3 เครื่องก่อน** (ปิด freeze → ลง `Agent-Setup.msi` → รีบูต → เปิด freeze)
   - ใช้ตาม "เช็กลิสต์ทดสอบ" ด้านล่างสัก 1 คาบ ค่อยลงครบ 40 เครื่อง
   - ข้อจำกัดเดิม: AgentTray เปิดเองผ่าน HKCU Run ของแต่ละบัญชี บัญชีที่ยังไม่เคยล็อกอินก่อน commit baseline จะไม่มี tray

## เช็กลิสต์ทดสอบในแล็บ (เรียงตามความสำคัญ)

**ต้องผ่านก่อนลงครบ 40 เครื่อง**
- [ ] เครื่อง pilot ขึ้นออนไลน์ใน Console และ Dashboard นับจำนวนถูก
- [ ] บล็อกโปรแกรมได้ตามกฎ และโผล่ในเหตุการณ์ล่าสุด
- [ ] ล็อกจอ/ปลดล็อก (รวมปุ่ม "ล็อกทั้งห้อง" ใน Dashboard ต้องล็อกเฉพาะห้องที่เลือก) · **ยังไม่เคยกดทดสอบจริง**
- [ ] ส่งข้อความขึ้นจอ
- [ ] tray เปลี่ยนไอคอนถูก: ปกติ = ติ๊กเขียว · ถอดสาย LAN = ป้ายเทา · หยุด service Agent = ป้ายแดง
- [ ] รีบูตเครื่อง pilot แล้วทุกอย่างกลับมาเอง (disk freeze)

**ฟีเจอร์ใหม่ที่ควรลองในคาบจริง**
- [ ] Live View: เลือกห้องแล้วเห็นภาพทุกเครื่อง, ปรับขนาด, ตัวกรอง, ดับเบิลคลิกเปิด Screen View · **ยังไม่เคยทดสอบกับ VNC จริง**
- [ ] ส่งจอครู: แถบแดงหุบ/กาง, กล่องเครื่องมือ (ปากกา/ไฮไลต์/ยางลบ/สี/ขนาด), ซูม + แผนที่เล็ก
  - ดูที่จอนักเรียนว่าเห็นเส้นที่เขียนและภาพที่ซูม แต่**ไม่เห็น**แถบแดง/กล่องเครื่องมือ/แผนที่
- [ ] ยกมือ: นักเรียนกดยกมือ → ขึ้นคิวใน Dashboard
- [ ] โหมดสอบ + allow-list และบล็อกเว็บรายห้อง
- [ ] แจก/เก็บไฟล์
- [ ] เปิด URL/โปรแกรมบนเครื่องนักเรียน
- [ ] แผงขวา: เลือกเครื่อง → ตั้งค่าเครื่อง/โปรแกรมที่เปิดอยู่/คำสั่งค้าง และ "สร้างกฎจากโปรแกรมนี้" · **ยังไม่เคยทดสอบกับ Agent จริง**

**ข้อจำกัดที่รู้แล้ว**
- หน้าแจกไฟล์/รายงานผลคำสั่งตอนนี้บังหน้าหลักระหว่างเปิด (ต้องปิดก่อนจึงจะกดหน้าหลักได้)
- ดับเบิลคลิกใน Live View จะเห็นภาพขยายแวบหนึ่งก่อนสลับไป Screen View
- รายการงานค้างและ field test ของขั้น 1–4 ที่เหลือ ดูได้ในตารางสถานะของ `docs/roadmap.md`
