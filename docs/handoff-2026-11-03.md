## วิธีทำงานที่ผู้ใช้ต้องการ

- **รูปแบบ session:**
  - session หลักเป็น orchestrator สั่ง worker ผ่าน Agent tool โดยใช้ agent type `wp-worker` (มีใน `.claude/agents/wp-worker.md`) ใช้ `model: sonnet` และ `isolation: worktree`
  - ผู้ใช้บอกชัดว่าอยากให้สั่งผ่าน session หลักแบบนี้ ไม่ต้องให้ผู้ใช้เปิด session แยกเอง
- **ภาษารายงาน:** worker รายงานเป็นภาษาอังกฤษแบบสั้นเพื่อประหยัด token ส่วน session หลักสรุปให้ผู้ใช้เป็นภาษาไทย
- **จำนวน worker:** รันพร้อมกันได้ไม่เกิน 2 ตัว
- **ประหยัด token:** ใน prompt ให้ชี้ไปที่ไฟล์แทนการแปะเนื้อหา
- **เมื่อติด limit:** ถ้าเป็น weekly limit ให้ commit งานค้างเป็น WIP ลง branch ของ WP นั้นก่อน แล้วค่อยลบ worktree ถ้าเป็น session limit ให้ใช้ SendMessage สั่ง worker ทำต่อหลังรีเซ็ต
- **หลัง merge ทุกครั้ง:** build ทั้ง solution → ลบ worktree (path ยาวต้องใช้ `rd /s /q \\?\...`) → ลบ branch → อัปเดตตารางสถานะใน roadmap

## บทเรียนจากรอบนี้ (สำคัญ)

- **UI ที่ครูหรือนักเรียนกดใช้ต้องทดสอบด้วย input จริง**
  - ใช้ harness WPF ชั่วคราวใน `%TEMP%` ที่อ้างโปรเจกต์จริง เปิดหน้าต่างจริงบนจอ ขับด้วย SendInput (`SetCursorPos`/`mouse_event`/`keybd_event`) แล้วจับภาพด้วย `ScreenCaptureService.CapturePrimaryScreenJpeg`
  - การอ่านโค้ดอย่างเดียวพลาดบั๊กจริงมาแล้ว 2 ตัว คือเขียนบนจอไม่ติดเส้น และแถบหลุดนอกจอ
  - harness ต้องฝัง `Theme/icon.ico` เป็น Resource ที่ path เดียวกัน และตั้ง `ShutdownMode=OnExplicitShutdown` ไม่อย่างนั้น pack URI แบบ relative จะหาไฟล์ไม่เจอ
- **ห้ามใช้ `AllowsTransparency="True"` กับหน้าต่างที่ต้องซ่อนจากการจับภาพ:** `SetWindowDisplayAffinity` จะล้มเสมอ (error 8) ให้ใช้หน้าต่างทึบ ถ้าต้องการคลิกทะลุให้เติม `WS_EX_LAYERED|WS_EX_TRANSPARENT` เอง และทำมุมโค้งด้วย `SetWindowRgn`
- **หน้าต่างโปร่งใสที่ต้องรับเมาส์ ห้ามมีพื้นหลัง alpha 0:** Windows จะส่งเมาส์ทะลุไป ให้ใช้ `#01000000`
- **หน้าต่างที่ลากได้หรือเปลี่ยนขนาดได้ ต้อง clamp ให้อยู่ใน `SystemParameters.WorkArea`**
- **Console ในแล็บไม่ได้อยู่เครื่องเดียวกับ Server** (Server คือ 192.168.17.249) ฟีเจอร์ที่อ้าง path บนเครื่อง Server ต้องมีทางดาวน์โหลดผ่าน API
- **Server ทดสอบ:**
  - ตั้งค่าผ่าน env `Server__Port`, `ConnectionStrings__DefaultConnection`, `ConnectionStrings__ActivityLogConnection`, `FileTransfer__StoragePath`
  - เมื่อเจอ DB ใหม่ Server จะ backup ลง `C:\ProgramData\OnionProcOparetor\backups` จริงทันที ให้จดรายชื่อไฟล์ก่อนสตาร์ต แล้วลบเฉพาะไฟล์ที่เพิ่มขึ้น
  - ห้ามใช้ `Remove-Item` แบบ pipe เพราะถูกบล็อก ให้ใช้ `[IO.File]::Delete` กับชื่อไฟล์ตรงๆ
  - ลำดับตั้งค่าแอดมิน: `POST /api/auth/setup` → login `Administrator` รหัสว่าง → `POST /api/admin/users/1/change-password` → login ใหม่ → `PUT /api/settings/backup` (ใส่ storagePath เป็น temp)
  - เครื่องสมมติสร้างได้ด้วย `GET /api/poll/{guid}?machineName=...`
- **Python heredoc ที่มี path Windows ให้ใช้ raw string** (`r"""..."""`) ไม่อย่างนั้น `\b`/`\U` จะกลายเป็นอักขระควบคุม
- **Agent รันจริงบนเครื่อง dev ไม่ได้** เพราะต้องใช้ LocalSystem ฝั่งนักเรียนจึงทดสอบได้แค่ logic กับภาพ preview
